# Linearization Lab

## Files
Keep `index.html` and all five JPG graph images together in the same folder.

## GitHub Pages
1. Create a public GitHub repository.
2. Upload all files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, `main`, and `/ (root)`.
5. Save, wait for publishing, and use the displayed Pages URL in Google Classroom.

Students can use **Export results as JPG** to download a submission image.
